# Glowing-Login-Form

A modern and responsive **Glowing Login Form** built using **HTML, CSS, and JavaScript**.

This project demonstrates how to create a stylish login interface with a **gradient animated background, glassmorphism design, glowing effects, form validation, password visibility toggle, and responsive layout**.

---

## 📌 About This Project

The Glowing Login Form is a frontend web project designed to create a modern and attractive login experience.

The interface includes:

- Username input field
- Password input field
- Show/Hide password functionality
- HTML5 form validation
- Animated gradient background
- Glassmorphism login card
- Neon glowing border and shadow effects
- Gradient login button
- Hover effects
- Responsive design for mobile devices
- Register link

This project is mainly focused on improving **HTML, CSS, and JavaScript frontend development skills**.
